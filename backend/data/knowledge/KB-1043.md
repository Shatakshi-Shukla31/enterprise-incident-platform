---
id: KB-1043
title: Failed database backups and restore tests
category: database
access: internal
team: Database Administration
---
Symptoms: a nightly backup job fails, or a restore test does not complete.

Read the backup job log. A full backup repository is the most common cause, so check capacity and retention settings.

Rerun the backup after fixing the cause and confirm that it finished. A backup that has not been restored is not proven, so run the verification job as well.

Two consecutive missed backups of a production database must be escalated to the on-call database manager.
