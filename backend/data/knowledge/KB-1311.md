---
id: KB-1311
title: Windows updates fail or appear stuck
category: hardware
access: public
team: End User Computing
---
Symptoms: an update sits at the same percentage, repeats after every restart, or fails with an error code such as 0x80070002.

Leave it for an hour before acting, because large updates can look frozen.

Connect to mains power and to the office network or VPN.

Free at least 20 GB of disk space.

Run the Windows Update troubleshooter from Settings.

If the same update fails twice, raise an incident with the error code from Update history.
