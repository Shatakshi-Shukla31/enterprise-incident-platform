---
id: KB-1064
title: Exposed secrets and accidental data disclosure
category: security
access: restricted
team: Security Operations
---
Symptoms: an API key is found in a public repository, or sensitive data was sent or shared externally.

Treat any exposed secret as compromised, even if it was removed from the repository quickly. Rotate it first and investigate afterwards.

Review the provider's logs for use of the key since the time of exposure.

For data sent to the wrong recipient, attempt a message recall, ask the recipient to delete it, and notify the privacy office, which decides whether regulators or customers must be told.
