title: Requesting new software
category: software_application

Symptoms: you need an application that is not in the software centre.

Check the software centre first, because approved titles install without admin rights.

Otherwise raise a request naming the product, the version and the business reason.

Security reviews new software, which usually takes up to 10 working days.

Installing software from the internet, or using free trials with company data, is not allowed.
