---
id: KB-1304
title: Laptop disk is full
category: hardware
access: public
team: End User Computing
---
Symptoms: Windows shows a low disk space warning, updates fail, or files cannot be saved to the C drive.

Open Settings, System, Storage to see what is using the space.

Empty the Recycle Bin and clear out the Downloads folder.

Right-click large OneDrive folders and choose Free up space, which keeps them online only.

Turn on Storage Sense to remove temporary files automatically.

Never delete files from the C:\Windows folder.
