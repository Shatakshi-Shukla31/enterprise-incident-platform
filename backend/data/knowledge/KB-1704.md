---
id: KB-1704
title: Email or file blocked by data loss prevention
category: security
access: public
team: Security Operations
---
Symptoms: an email is held or a file upload is stopped with a policy notice, because it may contain sensitive data such as card numbers.

The notice names the rule that matched, such as payment card numbers or personal data.

Remove the sensitive information, or send it through the approved secure sharing service.

If it is a false alarm, use the justification option in the notice or ask Security Operations.

Never use personal email or rename a file to get around the check.
