id: KB-1074
title: SharePoint and OneDrive sync errors
category: email_collaboration
access: internal
team: Application Support
---
Symptoms: a document library will not sync, uploads fail, or a site returns an error.

Check the OneDrive client's status icon for the affected file. Very long file paths and unsupported characters are common causes.

Reset the sync client if many files are stuck.

If uploads fail for everyone on a site, check the site's storage quota and whether it has been set to read-only. A site that returns an error for all users should be checked against the service health page.
