id: KB-1014
title: Troubleshooting single sign-on and SAML failures
category: access_identity
access: internal
team: Identity & Access
---
Symptoms: redirect loops, or an error from the identity provider when opening an application.

Capture the correlation ID shown on the error page and search for it in the sign-in logs.

A redirect loop for one user usually means a stale session, so clear the cookies or try a private window. A failure for all users of one application points to an expired SAML signing certificate or a changed reply URL.

Compare the certificate thumbprint configured in the application with the current one from the identity provider, and rotate it during a change window.
