---
id: KB-1600
title: Pod stuck in Pending or FailedScheduling after a deployment
category: cloud_infrastructure
access: internal
team: Cloud Platform
---
Symptoms: a pod stays in Pending, the deployment does not roll out, or events show FailedScheduling.

Run kubectl describe pod and read the Events section.

Insufficient cpu or memory means the requests exceed what any node has free, so lower the requests or add nodes.

An unbound PersistentVolumeClaim means storage was not provisioned.

Check node selectors, taints and affinity rules, which can exclude every node.
