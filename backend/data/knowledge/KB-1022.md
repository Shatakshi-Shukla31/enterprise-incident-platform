---
id: KB-1022
title: Printer offline or print jobs stuck
category: hardware
access: public
team: End User Computing
---
Symptoms: print jobs stay in the queue, or the printer shows as offline.

Check the printer's panel for a paper jam or an empty tray. Clear any jam, then close all doors firmly.

Cancel your stuck jobs and print again. If the queue will not clear, remove the printer from your laptop and add it again from the print portal.

If nobody can print, report the printer's asset tag so that End User Computing can restart the print service for that location.
