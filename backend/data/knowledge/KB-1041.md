id: KB-1041
title: Blocking queries and lock contention
category: database
access: internal
team: Database Administration
---
Symptoms: batch jobs run for hours, or a service stalls while waiting on the database.

Find the head of the blocking chain in the lock views. Check what that session is doing before terminating it, because cancelling a long transaction can trigger a long rollback.

If a query slowed suddenly, compare its plan with the previous one. Stale statistics are the usual cause, so run ANALYZE on the affected tables.

Schedule heavy batches away from business peaks and keep transactions short.
