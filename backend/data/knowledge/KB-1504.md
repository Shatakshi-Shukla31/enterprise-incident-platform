---
id: KB-1504
title: Failed or blocked schema migration
category: database
access: internal
team: Database Administration
---
Symptoms: a release is stuck on a migration, an ALTER TABLE is waiting, and queries are queueing behind it.

ALTER TABLE needs a brief exclusive lock. It waits behind long queries, and every later query then waits behind it.

Set lock_timeout so that a migration fails quickly rather than blocking everyone.

Create indexes with CREATE INDEX CONCURRENTLY, outside a transaction.

If a migration failed part way, check the version table before running it again.

Split risky changes across releases: add the new column, move the data, then remove the old one later.
