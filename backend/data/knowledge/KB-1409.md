---
id: KB-1409
title: File is locked for editing by another user
category: software_application
access: public
team: Application Support
---
Symptoms: Word or Excel says a document is locked or in use by someone, or opens it read-only, when nobody seems to have it open.

Ask the named person to close it, if a name is shown.

Open the file from SharePoint or OneDrive rather than a shared drive, so several people can edit at once.

A lock can remain after a crash. Close all Office applications, then sign out and back in.

Support can close a stuck session on the file server if it remains locked.
