---
id: KB-1100
title: Work website blocked by the web proxy or content filter
category: network
access: public
team: Network Operations
---
Symptoms: a business website shows an access blocked page or a category warning, while other sites load normally.

A block page that names a category means the filter is working as configured, not that the site is down.

Note the category and the reference number on the block page, because Network Operations needs both.

Request an exception through an incident that gives the full address and the business reason. Exceptions for file sharing and personal email need approval from Security Operations.

If many sites fail at once with proxy errors, the proxy itself may be down. Say so in the incident so it is handled as an outage.
