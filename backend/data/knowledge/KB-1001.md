---
id: KB-1001
title: VPN disconnects repeatedly on the corporate client
category: network
access: public
team: Network Operations
---
Symptoms: the VPN client connects and then drops every few minutes, or loops on reconnecting.

Check your home connection first. If other sites stutter too, the fault is probably local. Move closer to the router or use a wired connection.

Update the client to the version in the software portal. Versions older than two releases lose their session when the gateway renegotiates keys.

Switch the protocol from UDP to TCP in the client settings if the tunnel drops during video calls. Some home routers discard long UDP sessions.

If drops continue, raise an incident and attach the client log from Help, then Export Diagnostics, with the time of the last drop.
