id: KB-1800
title: Getting access to a shared mailbox
category: email_collaboration
access: public
team: End User Computing
---
Symptoms: a team inbox is missing from Outlook, or you cannot send from it.

The mailbox owner approves access requests.

It appears by itself within an hour, once Outlook has been restarted.

To send as the mailbox, choose it in the From field.

If it is still missing after a day, open it from Outlook on the web and raise an incident.
