title: Build pipeline and deployment failures
category: cloud_infrastructure

Symptoms: a pipeline fails at the deploy stage, runners are out of capacity, or terraform apply fails.

Read the first error in the stage log, not the last. Later errors are usually consequences of the first.

If jobs are queued, check the runner pool's capacity and any stuck jobs.

For a Terraform failure, check for state lock contention before forcing an unlock, and confirm that nobody else has an apply in progress. Resolve drift deliberately, never by editing the state file by hand.
