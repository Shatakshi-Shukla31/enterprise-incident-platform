---
id: KB-1015
title: Shared drive access denied
category: access_identity
access: internal
team: Identity & Access
---
Symptoms: a user gets access denied, or repeated credential prompts, when opening a network share.

Confirm that the user belongs to the security group protecting the folder. Group changes only take effect after signing out and back in.

Repeated credential prompts usually mean a stale entry in Windows Credential Manager. Remove the entry for the file server and reconnect.

If the whole site loses access while permissions are correct, the cause is more likely the network path to the file server, so involve Network Operations.
