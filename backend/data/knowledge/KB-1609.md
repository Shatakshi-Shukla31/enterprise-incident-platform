---
id: KB-1609
title: Message queue backlog growing
category: cloud_infrastructure
access: internal
team: Cloud Platform
---
Symptoms: queue depth keeps rising, consumers fall behind, jobs are delayed, or the dead-letter queue is growing.

Check that consumers are running and not crash-looping.

Compare the publish rate with the consume rate to see which one changed.

Inspect the dead-letter queue for a poison message that blocks processing.

Add consumers only if the systems behind them can take more load.

Consumers must be idempotent, because messages can be delivered twice.
