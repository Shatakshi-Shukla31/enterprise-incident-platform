title: Diagnosing packet loss, latency and slow file transfers
category: network
access: internal
team: Network Operations
---
Symptoms: transfers between sites run far below link speed, calls are choppy, or applications time out at random.

Measure before changing anything. Run ping and traceroute to the destination during the problem and save the output.

High latency at one hop that later hops do not share is usually router control-plane behaviour, not real loss.

Check interface counters for errors, discards and duplex mismatch on every link in the path.

Test throughput with iperf between the two sites and compare it with the contracted link speed.

Check MTU when small packets pass but large transfers hang, especially across a VPN or GRE tunnel.
