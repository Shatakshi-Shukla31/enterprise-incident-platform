---
id: KB-1707
title: How to report a security concern
category: security
access: public
team: Security Operations
---
Symptoms: something seems wrong, but you are unsure whether it counts as a security issue or who to contact.

Report anything suspicious, even if you are unsure, because a false alarm costs nothing.

Raise an incident with the security category and high urgency.

Include what you saw, when it happened, and any accounts or devices involved.

Leave the investigation to Security Operations, and avoid contacting the suspected attacker.
