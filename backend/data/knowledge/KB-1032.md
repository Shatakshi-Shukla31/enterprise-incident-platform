id: KB-1032
title: Application performance degradation
category: software_application
access: internal
team: Application Support
---
Symptoms: pages load slowly for many users, or requests time out, often at month end.

Open the service dashboard and look at latency, error rate and saturation. Determine whether the slowdown is in the application tier or a dependency.

If database time dominates, involve Database Administration and look for blocking queries. If CPU or memory on the application tier is saturated, scale out, then look for a recent change.

A rolling restart may help temporarily when memory keeps growing, but capture a heap dump first so that the leak can be found.
