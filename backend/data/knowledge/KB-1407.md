---
id: KB-1407
title: Application fails to start after a deployment
category: software_application
access: internal
team: Application Support
---
Symptoms: a service crashes on start-up after a release, with errors such as class not found, module not found or a version mismatch.

Read the first error in the start-up log, not the last one.

Compare configuration and environment variables with the previous release, because a missing value is a common cause.

Check that dependency and runtime versions match what the build expected.

If users are affected, roll back first and diagnose afterwards.
