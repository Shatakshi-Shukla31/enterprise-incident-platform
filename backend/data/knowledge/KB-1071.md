title: Mail flow delays, bounces and relay errors
category: email_collaboration
access: internal
team: Application Support
---
Symptoms: external mail bounces with a relay error, or delivery is delayed for many users.

Run a message trace for an affected message to see where it stopped. The bounce code tells you whether the rejection came from us or from the recipient's server.

Check that the sending IP is not on a blocklist and that SPF and DKIM records are valid after any DNS change.

If mail is queued on the transport host, resolve the cause first, then retry the queue.
