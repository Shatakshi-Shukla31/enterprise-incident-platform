---
id: KB-1503
title: Table bloat and autovacuum falling behind
category: database
access: internal
team: Database Administration
---
Symptoms: a table keeps growing while its row count does not, dead tuples pile up, or transaction ID wraparound warnings appear.

Check n_dead_tup and last_autovacuum in pg_stat_user_tables.

Find long-running transactions first, because they stop vacuum from removing dead rows.

Lower autovacuum_vacuum_scale_factor on large, busy tables.

VACUUM FULL takes an exclusive lock, so prefer pg_repack on a live system.

Treat wraparound warnings as urgent.
