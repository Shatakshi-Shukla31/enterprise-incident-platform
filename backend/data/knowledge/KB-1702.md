---
id: KB-1702
title: Found a USB drive, memory stick or unknown device
category: security
access: public
team: Security Operations
---
Symptoms: you found a memory stick or other device, or something unknown is attached to your computer.

Never plug it in to see whose it is, because that is exactly what an attacker hopes for.

Hand it to the IT desk or to Security Operations.

If it is already connected, disconnect from the network, leave the computer on, and report a security incident.
