---
id: KB-1400
title: Website or web application not loading correctly
category: software_application
access: public
team: Application Support
---
Symptoms: pages look broken, buttons do nothing, or a site keeps showing an old version.

Try a private or incognito window. If it works there, a cached file or a browser extension is the cause.

Clear the cache and cookies for that site.

Disable extensions one at a time to find the one responsible.

If colleagues see the same fault, the problem is probably on the server, so raise an incident.
