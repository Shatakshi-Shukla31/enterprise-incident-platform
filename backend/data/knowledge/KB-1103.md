---
id: KB-1103
title: No network connection or a 169.254 address
category: network
access: public
team: Network Operations
---
Symptoms: the network icon shows no internet or limited connectivity, or ipconfig shows an address beginning with 169.254.

An address starting with 169.254 means the device did not receive one from DHCP.

Check the cable at both ends and try another wall port. If you use a dock, connect directly to the laptop to rule out the dock.

Run ipconfig /release and then ipconfig /renew in a command prompt.

Restart the device if the adapter still has no valid address.

If colleagues nearby are offline too, report a shared outage and include your location.
