id: KB-1052
title: Object storage and persistent volume errors
category: cloud_infrastructure
access: internal
team: Cloud Platform
---
Symptoms: a bucket returns errors, a persistent volume fills up, or file gateway latency rises.

A 403 from object storage means a policy or credential problem, so check any recent IAM changes and the expiry of the service's credentials. A 503 suggests request throttling, so add backoff to the client.

Extend a full persistent volume if its storage class allows expansion.

For file gateway latency, check the gateway's cache disk usage and its upload backlog.
