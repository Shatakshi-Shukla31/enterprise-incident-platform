---
id: KB-1302
title: Laptop is slow or freezes
category: hardware
access: public
team: End User Computing
---
Symptoms: applications take minutes to open, the laptop freezes, or the fans run constantly.

Restart first. Laptops that have not been restarted for weeks slow down, and pending updates make it worse.

Open Task Manager and sort by CPU and memory to see what is using the resources.

Close browser tabs you do not need, because they are often the largest memory user.

Keep at least 15 percent of the disk free.

If it stays slow, raise an incident with a screenshot of Task Manager.
