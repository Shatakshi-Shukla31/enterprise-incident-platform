---
id: KB-1102
title: Mapped network drive missing or shows a red cross
category: network
access: public
team: Network Operations
---
Symptoms: a drive letter has disappeared from File Explorer, or it shows a red cross after you sign in.

Connect to the office network or VPN first, then open the drive. Windows marks a drive as disconnected until it can reach the server.

Run gpupdate /force in a command prompt, then sign out and back in, because drive mappings are applied at sign-in.

If the drive opens but refuses a folder with an access error, see the shared drive access article instead.

Reconnect the drive by hand using the server path your team has published.
