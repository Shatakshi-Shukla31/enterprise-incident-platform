title: Outlook search does not find messages
category: email_collaboration
access: public
team: End User Computing
---
Symptoms: searching your inbox does not return messages you know are there.

Check whether indexing has finished, in File, Options, Search, Indexing Options.

Outlook keeps only recent mail on the laptop, so search older messages in Outlook on the web.

Rebuild the index from Indexing Options, Advanced. This can take several hours.
