---
id: KB-1406
title: Service memory keeps growing until it restarts
category: software_application
access: internal
team: Application Support
---
Symptoms: memory climbs steadily, the process is killed for running out of memory, and a restart only helps for a while.

Graph memory over several days to confirm steady growth, rather than a cache filling up to its limit.

Take a heap dump before restarting, because a restart destroys the evidence.

Compare two dumps taken hours apart to see which objects are growing.

Common causes are unbounded caches, listeners that are never removed and connections that are never closed.

Schedule rolling restarts as a stopgap and raise a problem record.
