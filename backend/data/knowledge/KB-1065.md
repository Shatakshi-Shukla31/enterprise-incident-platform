id: KB-1065
title: Handling critical vulnerabilities
category: security
access: internal
team: Security Operations
---
Symptoms: a critical CVE or a penetration test finding affects a service.

Confirm whether the vulnerable component is in use and reachable. Scanner findings can be false positives for unused code paths.

Critical issues exposed to the internet must be patched or mitigated within 72 hours. Internal-only critical issues have 14 days.

If a patch is not available, apply a compensating control such as a WAF rule, and record an exception with an owner and a review date.
