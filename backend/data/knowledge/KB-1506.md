---
id: KB-1506
title: Requesting read access to production data
category: database
access: internal
team: Database Administration
---
Symptoms: an analyst or developer wants to query live production tables.

Use the reporting replica rather than the primary.

Requests name the tables, the reason and an end date, and the data owner approves them.

Personal data is only available through masked views.

Access expires automatically after 30 days.

Never copy production data to a laptop or a test environment.
