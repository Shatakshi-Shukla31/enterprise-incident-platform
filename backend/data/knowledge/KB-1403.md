---
id: KB-1403
title: Recover a deleted or overwritten file
category: software_application
access: public
team: Application Support
---
Symptoms: a file was deleted by mistake, or you saved over a version you still need.

Check the Recycle Bin first, then stop editing the file so that nothing else is overwritten.

For OneDrive and SharePoint files, use Version history to restore an earlier copy. Deleted items stay in the site recycle bin for 93 days.

On a shared drive, right-click the folder, choose Properties, then Previous Versions.

For older losses, raise an incident with the path and the last date the file was good. Backups are kept for 30 days.
