---
id: KB-1033
title: Problems after a Windows or application patch
category: software_application
access: internal
team: Application Support
---
Symptoms: a plugin stops loading or macros fail straight after an update.

Identify the update from the device's update history. Check whether the same patch has been reported as a known issue.

If the failure affects many users, ask End User Computing to pause the patch ring while it is investigated.

A single patch can be removed from one device as a workaround, but it must be reapplied once a fix ships. Record the exception in the incident.
