---
id: KB-1303
title: Blue screen or unexpected restarts
category: hardware
access: public
team: End User Computing
---
Symptoms: the computer shows a blue stop screen, crashes with a stop code, or restarts on its own.

Note the stop code on the screen and what you were doing at the time.

Disconnect the dock and USB devices, then restart, because faulty peripheral drivers are a common cause.

Install pending updates, including drivers from the software centre.

If it happens more than once, raise an incident with the stop code. Support can read the crash files in C:\Windows\Minidump.

Crashes with different stop codes each time suggest failing memory or storage, so save your work to OneDrive.
