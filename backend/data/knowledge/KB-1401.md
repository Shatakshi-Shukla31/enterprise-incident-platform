---
id: KB-1401
title: Word, Excel or Outlook crashes or will not open
category: software_application
access: public
team: Application Support
---
Symptoms: an Office application closes as soon as it opens, or reports that it has stopped working.

Hold Ctrl while opening the application to start it in safe mode. If it opens, an add-in is the likely cause.

Disable add-ins in File, Options, Add-ins, then turn them back on one at a time.

Run Quick Repair from Settings, Apps, Installed apps.

Try a different file, because a single damaged document can cause the crash.
