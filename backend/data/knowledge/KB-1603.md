---
id: KB-1603
title: Autoscaling does not add capacity
category: cloud_infrastructure
access: internal
team: Cloud Platform
---
Symptoms: load is rising and latency is climbing, but the replica count does not change, or the HPA shows unknown.

Run kubectl describe hpa. An unknown metric means the metrics server is not reporting.

CPU-based scaling depends on resource requests, so a pod without them cannot be scaled.

Check whether the deployment has reached maxReplicas.

If new pods stay Pending, check the cluster autoscaler and your cloud quota.

Scale by hand as a stopgap.
