---
id: KB-1708
title: Phone calls claiming to be from IT support
category: security
access: public
team: Security Operations
---
Symptoms: a caller says they are from the helpdesk or a vendor, and asks for your password, an MFA code or remote access.

Hang up and call the service desk using the number on the portal.

Real support staff will never ask for your password or your MFA code.

Never install a remote access tool because a caller asked you to.

If you have already given details, change your password and report a security incident.
