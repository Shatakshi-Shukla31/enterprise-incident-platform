---
id: KB-1602
title: Kubernetes node NotReady or under disk pressure
category: cloud_infrastructure
access: internal
team: Cloud Platform
---
Symptoms: a worker node shows NotReady, pods are evicted, or the node reports DiskPressure or MemoryPressure.

Run kubectl describe node and read Conditions and recent Events.

Cordon and drain the node to move work away before repairing it.

For DiskPressure, remove unused images and check log volume.

Check that the kubelet is running and can reach the API server.

Replace an autoscaled node rather than repairing it.
