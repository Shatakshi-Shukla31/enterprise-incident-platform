---
id: KB-1404
title: API integration returning 401, 403, 429 or 5xx errors
category: software_application
access: internal
team: Application Support
---
Symptoms: an integration with a partner or another system starts failing with HTTP errors.

A 401 means the credentials were rejected, so check whether a token or client secret has expired.

A 403 means the identity is valid but lacks permission, or the source address is not allowed.

A 429 means too many requests. Honour the Retry-After header and add backoff with jitter.

A 5xx means the provider failed. Retry only idempotent requests and check the provider's status page.

Log the correlation ID, because the provider will ask for it.
