id: KB-1003
title: Diagnosing internal DNS resolution failures
category: network
access: internal
team: Network Operations
---
Symptoms: internal hostnames do not resolve, or resolve only some of the time, while IP addresses still work.

Confirm the scope. Run nslookup against each resolver in turn. If a single resolver fails, remove it from rotation and restart its service.

Flush the client cache with ipconfig /flushdns and repeat the lookup. A success after flushing points to a stale record, so check the record's TTL and the last zone transfer.

If all resolvers fail for one zone, check that the zone's serial number matches on primary and secondary servers. A failed zone transfer is the usual cause.
