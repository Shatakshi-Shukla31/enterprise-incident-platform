---
id: KB-1104
title: IP address conflicts and exhausted DHCP scopes
category: network
access: internal
team: Network Operations
---
Symptoms: clients report a duplicate address warning, or new devices on a subnet get no address while existing ones keep working.

Check scope usage on the DHCP server. Above 90 percent, clients start failing as their leases renew.

Shorten the lease on guest and wireless scopes, where devices come and go, before extending the range.

Compare the server that issued a lease with the approved list, because a rogue DHCP server hands out bad addresses.

For a conflict, find both devices from the ARP table and the switch MAC table, then move static devices to reservations outside the dynamic pool.
