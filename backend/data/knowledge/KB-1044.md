---
id: KB-1044
title: Database disk or tablespace filling up
category: database
access: internal
team: Database Administration
---
Symptoms: an alert reports the data volume above 90 percent, or the transaction log keeps growing.

Find what is using the space. Check for table bloat, a forgotten temporary table, and for inactive replication slots retaining WAL.

An inactive replication slot is a frequent cause of runaway log growth. Confirm that it is unused before dropping it.

Extend the volume if it is close to full, as a database that runs out of space will stop accepting writes. Afterwards, add capacity alerts at 75 percent.
