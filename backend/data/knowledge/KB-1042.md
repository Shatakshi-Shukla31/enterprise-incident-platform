---
id: KB-1042
title: Replication lag and stalled standby
category: database
access: restricted
team: Database Administration
---
Symptoms: a read replica returns stale data, or the standby has stopped applying logs.

Measure lag on the standby. If bytes are arriving but not being replayed, a long query on the standby may be holding replay back.

If WAL is not arriving, check the network between the hosts, and check for a replication slot problem or a missing WAL segment.

Do not promote a lagging standby without the database manager's approval, because it can lose committed transactions. Promotion is run through the approved failover runbook.
